# CodeBrain

A developer's AI-maintained second brain. The owner curates sources and directs the analysis; agents (Claude Code) do the writing, cross-referencing, and bookkeeping.

For the full operating manual (what goes where, how agents work, conventions), see [[CLAUDE]].

## Quick tour

| Folder | What lives here |
|---|---|
| [[raw]] | Immutable source material (articles, papers, attachments) |
| [[wiki]] | LLM-maintained synthesis — entities, concepts, summaries |
| [[projects]] | Active work, one folder per project |
| [[guides]] | Long-lived design guides, conventions, rules |
| [[archive]] | Retired projects |
| [[inbox]] | Quick capture, triage later |
| [[meta]] | Templates, references, tools, agent scratch |
