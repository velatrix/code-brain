# Spectium

## Goal

Multi-tenant SaaS (and on-prem distributable) visual test automation platform: users author tests as node-graph "flows" in a web editor; server-side runners execute them against real browsers (Playwright) and Android devices (Appium/UiAutomator2); results stream live and persist for history, reporting, traceability, and CI integration.

**Done: the store targets through Spectium** (repo `TestAppsFlows/`, BACKLOG B19 and B50–B53; 2026-09-29, fast-forwarded into `main` at `0ac67f6` and pushed).
- **What it is.** The user wanted flows in the product to test what had been built: not scripted UI passes, and not flows built by hand. `TestAppsFlows/seed.mjs` creates a **Store Demo** project through the API, with:
  - the store pair as applications, the APK as the Android app's first build;
  - a test case per CRUD operation, each automated on both platforms;
  - a shared sign-in flow per platform that re-seeds its data session first, so any flow starts from the same catalogue;
  - a suite per platform.
- **How the flows are made.** They are generated in the exact shape the editor saves, from the editor's own node registry, imported rather than copied. So they open and edit like hand-built flows (checked in the editor), and a re-run creates only what is missing.
- **What running them found:** four product defects, each fixed with tests and red checks.
  - An idle multi-slot web runner hardly ever asked for batch work, so a suite waited 7 min 22 s to start. It now starts in 0.19 s (B50).
  - Android's Clear first and Erase Text left a Flutter field's text in place (B51).
  - A Swipe within a full-width element started in the Back gesture zone and closed the app (B52).
  - A Swipe dropped from the palette had a Distance of 0 and moved nothing while passing (B53).
- **Result.** All eight flows and both suites pass on the web and on an API 35 emulator. B16's fix was confirmed against a real run. B17 (frames) and B18 (native dialogs) are still not run, so B19 stays in progress.
- **Lessons:** in the 2026-09-29 [[log]] entry for this work.
